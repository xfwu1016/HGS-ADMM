## Prerequisite order

The sample-consensus and pilot scripts read reference coefficients generated by the full `run_experiments.py` stage. The pilot postprocessing also checks the thirty overlapping 4×4 unit/budget configurations against those independently generated main runs. Thus the main experiment must finish before those stages. The table generator requires the main, consensus, sensitivity and exact-ridge outputs; the complete entry point also generates the pilot table.

The public datasets are loaded through `sklearn.datasets.load_diabetes` and `load_breast_cancer`. Standardization, parameter selection and train/validation/test indices are implemented and recorded in `run_experiments.py`; no external CSV is required.

The mathematical convergence and prediction theorems are established by the manuscript proofs. The code checks numerical implementations and exact examples; it does not replace those proofs.

Current extension: code/pilot_box.py and code/pilot_length.py generate results/pilot_box.csv and results/pilot_length.csv (Section 7.4).
